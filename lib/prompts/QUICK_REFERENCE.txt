5-STEP WORKFLOW
───────────────

1. Open: lib/prompts/GROK_PROMPT_EXTENDED.md

2. Copy EVERYTHING in that file

3. Paste into Grok/Claude

4. Fill in these 5 fields at the bottom:
   - Topic: [What's the discovery?]
   - Sources: [Papers with years: Smith et al. 2024, etc]
   - Audience: [General / Mixed / Specialists]
   - Angle: [What makes this unique/timely?]
   - Key finding: [Main result in 1-2 sentences]

5. Submit → Get JSON

6. Go to: /dashboard/articles/new
   Click: "Importer JSON"
   Paste: The full JSON
   Click: "Importer"
   Done!


WHAT YOU GET
────────────
✓ Simplified version (1500-2500 words)
✓ Scientific version (1800-3000 words)
✓ Proper JSON format for Neural Space
✓ Both auto-populate in editor
